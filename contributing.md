# Contributing

Thanks for helping keep the list current!

## What qualifies

- The shard is up and playable.
- Its website is reachable.

## Table conventions

- Rows are sorted alphabetically by shard name, ignoring spaces and punctuation.
- The second column shows the shard's main language as a flag emoji (`:gb:` for English, `:ru:` for Russian, and so on). A shard can have more than one flag.
- Link the final destination. If the site redirects, follow the redirect and link the URL it lands on.

## How to submit

No git needed: use the [Add a shard](https://github.com/felladrin/uo-is-not-dead/issues/new?template=add-a-shard.yml) form, or [Report a dead shard](https://github.com/felladrin/uo-is-not-dead/issues/new?template=report-a-dead-shard.yml). A maintainer picks it up from there.

With git: open a PR that adds a single row at the right alphabetical position, keeping the column alignment of the rows around it.

The weekly link checker validates every link in the list, so a dead link gets caught and reported even after it lands.
